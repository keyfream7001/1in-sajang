# 11월 세금 고지서 체크리스트

11월에 오는 종합소득세 고지서는 **중간예납**입니다. 작년 종합소득세의 절반을 미리 내고, 내년 5월 확정신고 때 이미 낸 세금으로 빼줍니다.

## 1. 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 무엇 | 작년 종합소득세의 1/2을 미리 내는 것 |
| 마감 | 2026년 11월 30일(월) |
| 안 내도 되는 경우 | 중간예납세액 50만 원 미만, 올해 새로 시작한 사업자 등 |
| 줄이는 방법 | 상반기 실적 기준 세액이 작년 기준의 30% 미만이면 추계액 신고 |
| 나눠 내기 | 1천만 원 초과 시 일부를 2027년 2월 1일(월)까지 분납 |
| 늦으면 | 납부지연 가산세 |

## 2. 고지서 받은 날 체크

- [ ] 고지 금액이 작년 종합소득세의 절반 정도가 맞는지 확인했다
- [ ] 올해 1~6월 실적이 작년보다 크게 줄었는지 따져봤다
- [ ] 크게 줄었다면 홈택스에서 추계액 신고를 검토했다 (11월 30일까지)
- [ ] 1천만 원이 넘으면 분납을 같이 신청했다
- [ ] 홈택스·손택스 또는 은행에서 11월 30일 전에 납부했다
- [ ] 헷갈리는 부분은 국세상담센터(126)에 물어봤다

## 3. 다음 11월을 위한 준비

- [ ] 사업용 통장과 별도로 '세금 통장'을 하나 만들었다
- [ ] 매출이 들어올 때마다 세금 몫을 정해진 비율로 먼저 옮긴다 (비율은 작년 세금과 매출을 보고 직접 정하기)
- [ ] 5월(종소세)·1월·7월(부가세)·11월(중간예납) 등 세금 나가는 달을 달력에 표시했다

## 4. 기억할 한 줄

통장에 있어도 세금 몫은 내 돈이 아닙니다. 들어올 때 먼저 떼어두면 11월이 무섭지 않습니다.
