# 월말 증빙 점검표

증빙은 5월에 몰아서 찾는 게 아니라 **받을 때 챙기는 것**입니다. 매달 말일, 아래 표를 10분만 채워 보세요.

## 1. 처음 한 번만 해두기

- [ ] 내 명의 카드를 홈택스 **사업용 신용카드**로 등록했다 (홈택스 › 계산서·영수증·카드 › 신용카드 매입 › 사업용 신용카드 등록 및 조회, 최대 50장)
- [ ] 등록 전에 사업용으로 쓴 카드 내역은 따로 모아 두었다 (자동 반영되지 않음)
- [ ] 구독·통신비·정기결제를 **카드 하나**로 모았다
- [ ] 휴대폰 사진첩·메모에 **'영수증' 앨범(폴더)** 을 만들었다

## 2. 매달 말일 점검

| 점검 항목 | 확인 | 메모 |
| --- | --- | --- |
| 이번 달 사업용 지출 중 3만 원 넘는 건은 카드·지출증빙용 현금영수증·세금계산서로 받았나 | | |
| 현금 결제는 사업자번호로 **지출증빙용** 현금영수증을 받았나 | | |
| 간이영수증·계좌이체만 있는 지출은 계약서·견적서·이체내역을 함께 저장했나 | | |
| 거래처 경조사비는 청첩장·부고 캡처와 이체내역을 저장했나 (건당 20만 원 이하) | | |
| 사업 통장 입출금에 한 줄 메모(누구·무엇)를 남겼나 | | |
| 개인 지출이 사업용 카드에 섞이지 않았나 | | |

## 기억할 것

- 3만 원 초과 지출에 적격증빙(세금계산서·계산서·신용카드매출전표·지출증빙용 현금영수증)이 없으면 증빙불비가산세(2%)가 붙을 수 있습니다.
- 세금을 줄이려고 필요 없는 지출을 만들지 마세요. **필요한 지출의 증빙을 빠짐없이 챙기는 것**이 먼저입니다.
